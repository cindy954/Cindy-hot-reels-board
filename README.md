# 신디의 핫 릴스 보드

수강생과 나눠 보는 데일리 릴스 레퍼런스 보드입니다. 최근 14일 안에 게시된 한국어 숏폼 가운데 조회수 20만 이상인 항목만 여행 / 자취·살림 / 다이어트로 나눠 모읍니다.

- 사이트: `index.html` · `styles.css` · `app.js`
- 데이터: `data/reels.json`

## 매일 업데이트하는 법

`data/reels.json`만 고치면 사이트가 그대로 따라갑니다. 코드는 건드릴 필요 없습니다.

1. `reels` 배열에 항목을 더하거나 지웁니다.
2. `generatedAt`(보드 기준 시각)과 `verifiedAt`(수치를 마지막으로 확인한 시각)을 현재 시각으로 바꿉니다.
3. 커밋하고 푸시하면 1분 안에 반영됩니다.

### 항목 형식

```json
{
  "id": "영상 ID(유튜브) 또는 숏코드(인스타)",
  "platform": "youtube | instagram",
  "category": "여행 | 자취·살림 | 다이어트",
  "title": "제목 그대로 (인스타는 캡션 첫 줄)",
  "creator": "크리에이터 표시 이름",
  "handle": "인스타 핸들 (@ 없이) 또는 null",
  "followers": 12345,
  "views": 123456,
  "viewSource": "YouTube | 인스타그램 원본 11.23 확인",
  "likes": 1234,
  "comments": 56,
  "likesHidden": false,
  "publishedAt": "2026-11-19T12:00:00+09:00",
  "durationSec": 20,
  "url": "https://www.youtube.com/shorts/XXXX",
  "ad": false,
  "point": "수강생에게 보여줄 벤치마킹 포인트 1~2문장"
}
```

### 지키는 규칙

- 조회수·게시 시각은 원본에서 확인한 값만 적습니다. 어림값이나 추정치는 넣지 않습니다. 20만 미만 항목으로 개수를 채우지 않습니다.
- 인스타그램 조회수는 인스타그램 원본(게시물 페이지·`/embed/captioned/`의 `video_view_count`)에서 확인한 재생 수를 씁니다. 좋아요·댓글·게시 시각도 원본에서 확인하고, `viewSource`에 확인 날짜를 남깁니다. 2026-11-18 이후 트래커(하입나우) 집계가 멈춰 새 릴스 수치를 받을 수 없고 트래커 값이 원본보다 크게 잡히는 경향이 있어(예: 한 항목 트래커 179만 vs 원본 91만), 카드에 보이는 숫자는 원본 기준으로 통일했습니다.
- 유튜브 쇼츠는 영상 페이지에서 조회수·좋아요를 읽고, 게시 시각은 채널 RSS 피드(`youtube.com/feeds/videos.xml?channel_id=…`)로 초 단위까지 확인합니다.
- 좋아요를 숨긴 계정은 `likesHidden: true`로 두고 카드에 '좋아요 비공개'로 표시합니다.
- 링크는 원본으로 바로 갑니다. 영상을 내려받아 다시 올리지 않습니다.
- `point`는 제목·캡션·길이를 보고 쓴 분석 메모라는 점을 카드에서 밝힙니다.
- 카드에 실명·이메일·전화번호·생일 등 개인정보를 넣지 않습니다.

## 로컬에서 보기

`python3 -m http.server` 로 이 폴더를 띄우고 `index.html`을 열면 됩니다.
