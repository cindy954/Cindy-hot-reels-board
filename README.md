# 신디의 48시간 핫 릴스 보드

수강생과 나눠 보는 데일리 릴스 레퍼런스 보드입니다. 최근 48시간 안에 게시된 한국어 숏폼 중 조회수가 높은 항목을 여행 / 자취·살림 / 다이어트로 나눠 모읍니다.

- 사이트: `index.html` · `styles.css` · `app.js`
- 데이터: `data/reels.json`

## 매일 업데이트하는 법

`data/reels.json`만 고치면 사이트가 그대로 따라갑니다. 코드는 건드릴 필요 없습니다.

1. `reels` 배열에 항목을 더하거나 지웁니다.
2. `generatedAt`(보드 기준 시각)과 `verifiedAt`(수치를 마지막으로 확인한 시각)을 현재 시각으로 바꿉니다.
3. 커밋하고 푸시하면 1분 안에 반영됩니다.

### 항목 형식

```json
{
  "id": "영상 ID",
  "platform": "youtube | instagram",
  "category": "여행 | 자취·살림 | 다이어트",
  "title": "제목 그대로",
  "creator": "크리에이터 이름 (핸들)",
  "views": 123456,
  "publishedAt": "2026-11-19T12:00:00+09:00",
  "durationSec": 20,
  "url": "https://www.youtube.com/shorts/XXXX",
  "point": "수강생에게 보여줄 벤치마킹 포인트 1~2문장"
}
```

### 지키는 규칙

- 조회수와 게시 시각은 원본 페이지에서 확인한 값만 적습니다. 어림값이나 추정치는 넣지 않습니다.
- 링크는 원본으로 바로 갑니다. 영상을 내려받아 다시 올리지 않습니다.
- `point`는 제목·설명·길이를 보고 쓴 분석 메모라는 점을 카드에서 밝힙니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 열면 `fetch`가 막혀 카드가 뜨지 않습니다. 로컬 서버로 열어 주세요.
